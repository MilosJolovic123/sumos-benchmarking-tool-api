# SuMos Benchmarking tool API Implementation
Izložićemo par pravila za praćenje GitFlow-a prilikom razvoja benchmarking tool-a.

### Pravila razvoja:

- Potrebno je odvajati `feat/naziv featurea` za korekcije
- Mogu se push-ovati te grane kao zasebne pa cemo onda na nivou remote repo-a da otvoramo PR-ove za merge
- Možemo zajedno pregledati PR-ove i na njima ostavljati komentare za potencijalne probleme pri merge-u
- Razmisliti o akcijama ako nešto bude moralo da se testira
